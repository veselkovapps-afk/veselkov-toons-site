Privacy Policy

Last updated: November 8, 2026

Veselkov Toons Uploader is a private tool used only by the Veselkov Toons channel owner to upload and schedule the channel's own videos and playlists on YouTube. It is not offered to the public.

What it accesses

With the owner's permission, it uses the YouTube API Services to upload videos, manage playlists and read the channel's own statistics. It does not access any other person's data.

What it stores

An access token is stored only on the owner's own computer. No data is sold, shared or sent to any third party. The owner can revoke access at any time at myaccount.google.com/permissions.

YouTube and Google

This tool uses YouTube API Services. See the YouTube Terms of Service and the Google Privacy Policy.
